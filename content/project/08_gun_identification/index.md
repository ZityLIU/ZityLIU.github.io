  # ── OVERVIEW ──────────────────────────────────────────────────
  - block: markdown
    content:
      title: Overview
      text: |-
        这是一套**战术竞技手游的枪械鉴定开箱动效**，由我**个人独立完成**。它要解决的不是"怎么把界面做好看"，而是一个更具体的产品问题：**玩家点下鉴定之后、引擎判定结果回流之前的那几秒空窗，应该给玩家什么。**

        我的答案是把这段空窗**做成一条情绪曲线**——用搜索过场承接不确定性，用爆点砸入制造重量，用扫描鉴定拉长期待，最后用结算光效兑现。更关键的是，同一条链路要**支持两个档位**：开出普通枪时保持克制干净，开出品质枪时必须把"开到金了"的惊喜感彻底放大。

        > A weapon identification reveal system for a tactical shooter, designed and built end-to-end in After Effects. Rather than filling the post-click wait with a generic loading state, it reframes that gap as an emotional curve — search, impact, reveal, appraisal, reward — and forks it into two tiers so that pulling a rare weapon feels categorically different from pulling a common one.

  # ── EMOTION DESIGN ────────────────────────────────────────────
  - block: markdown
    content:
      title: 核心设计 · 两个版本的情绪差
      subtitle: Where the Two Tiers Diverge
      text: |-
        做双档位最容易踩的坑，是**只把品质版做得"更亮更多"**——特效堆上去了，情绪却没起来。所以我先想清楚一件事：**惊喜感的本质是预期被打破。** 玩家在开箱前已经默认自己会开到普通枪，那么品质版要做的就不是"更华丽"，而是**在玩家以为流程该结束的时候，让它没有结束。**

        因此两版的分岔点被刻意放在**鉴定扫描**这一段，并且同时在三个维度上拉开距离——它们必须一起变，只改其中一个都会显得像是在敷衍。

  # ── BEAT 02+03 SLAM & GLITCH ──────────────────────────────────
  - block: markdown
    content:
      title: Beat 02–03 · 爆点砸入与像素扰动显形
      subtitle: Impact & Glitch Reveal
      text: |-
        搜索段刻意压了近 5 秒不给结果，**积攒的势能需要一记重击来释放**。这里的设计目标是"重量感"和"科技感"两件事，分别由转场和显形承担。

        扫描段是整条链路的**情绪主战场**，也是两个版本唯一真正分岔的地方。品质版在这里完成三件事：拉长时间、拉高饱和、把显形质感从冷静的线框推到发烫的热态。

          </p>
