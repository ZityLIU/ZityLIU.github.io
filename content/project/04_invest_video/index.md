  # ── OVERVIEW ──────────────────────────────────────────────────
  - block: markdown
    content:
      title: Overview
      text: |-
        这是一个面向短视频平台的 **AIGC 投资教育短片** 项目。我把原本带有较高理解门槛的金融概念，如 **PE / PB、Beta / Alpha、指数增强** 等，压缩成一个更适合普通观众理解的 **“真人情绪表达 × AI 助手打断纠偏”** 叙事结构，并在 **2h 内完成交付导向的内容方案搭建与成片表达设计**。

        项目核心目标不是单纯“做一条视频”，而是验证一套**可快速复用的内容工作流**：通过 **AIGC 辅助知识拆解、脚本压缩、AI 角色设计、图生视频微动作生成与后期包装**，把复杂知识转化为可观看、可传播、可继续扩展的短片形式。

        > A short-form finance explainer built with an AIGC-assisted workflow. Focus: turning abstract concepts into a lightweight Human × AI narrative, while packaging the whole process into a reusable pipeline for fast content delivery.

        **设计原则：** 不是直接堆叠知识点，而是先完成**知识降维**，再把概念嵌入“真人情绪表达 × AI 助手打断纠偏”的叙事框架中，让知识讲解自然地变成剧情的一部分。这样既保留信息密度，也更容易形成观看节奏与记忆点。

        ---

        项目中，AIGC 主要用于两件事：一是帮助我快速拆解概念之间的逻辑关系，二是把表达压缩成更口语化、更适合短视频镜头节奏的语言。最终形成的不是一篇解释文案，而是一套**脚本 + 贴士 + 节奏点**协同工作的内容表达结构。

            </p>

        **角色定位：** A宝不是单纯的视觉装饰，而是视频中承担“打断、提醒、解释、缓冲节奏”功能的 AI 投资助手。  
        在视觉上，我围绕“亲和力 + 科技感 + 可系列化复用”快速迭代提示词，使其既适合知识型内容，又不会显得过度卡通化。

        ---

        **动效策略：** 为了避免传统 3D 角色绑定与动画制作的成本，我采用了更适合短周期项目的方案：通过图生视频生成**低振幅微动作素材**。  
        重点不是复杂表演，而是保证角色形象稳定、易于后期拼接，并沉淀成一组可被反复调用的动态资产。
