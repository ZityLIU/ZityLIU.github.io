About Me

我是 刘芷汀（Zhiting Liu），香港科技大学（广州）数字媒体与艺术方向全奖研究型硕士，目前专注于 游戏动效设计、游戏特效与 Technical Art。2026 年加入 腾讯科技有限公司担任游戏动效实习生，先后参与国民级战术竞技手游《和平精英》及 3A 武侠动作 ACT 游戏《雪中悍刀行》相关项目的 UI 动效设计与制作。

我擅长 AE → UE5 的实时动效工作流，能够完成从动效预演、特效拆解到 UMG、材质与 Blueprint 交互落地的完整制作流程，并具备独立完成游戏 UI 动效原型与引擎内效果还原的能力。

此外，我熟悉 AI 辅助设计与开发工作流，能够使用 Cursor / Claude Code 等工具提升原型开发与视觉迭代效率。长期的游戏与内容创作经历也让我对竞技反馈、叙事 UI 与风格化视觉表达保持高度敏感；个人内容账号累计 1000 万+播放量、20 万+粉丝，具备良好的审美判断、内容表达与快速迭代能力。

我预计于 2027 年 8 月毕业，目前面向 2027 届秋招 / 春招，持续关注 游戏动效设计、游戏特效设计及 Technical Art 相关机会，欢迎通过邮件 zityliu@gmail.com 与我联系。
