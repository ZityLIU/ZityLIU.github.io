01 · 恭喜获得终版

由主图形纹饰出现、物品出现、流光边框三个细节效果合成的完整庆祝演出。

恭喜获得终版 · 完整合成演出

主图形纹饰 · 四层系统

水墨旋转荡开入场，叶片内部持续流转

形态与内部材质

Solid 旋转排布 + Boa 出形；水墨扭曲驱动入场泼溅，flow13_2 驱动持续流转。

轮廓系统

金色噪声套轮廓蒙版做明暗轮替，曲线+色相饱和度染金，叠加扭曲噪声做断续描边。

光晕系统

中心亮四周暗遮罩打底 + 光晕贴图出现放大，铺出基础能量光源。

气场与爆点

柔光/星芒/扫光/光晕球壳/爆发底光五类素材叠加，缩放与不透明度堆节奏。

物品出现 · 七层结构与弥散仙气

品质光晕 → 环境仙气 → 爆发光球 → 物品显形 → 品质框反馈

七层结构（唯一替换素材：物品 PNG）

品质光晕 → 环境仙气/雾气 → 爆发光球+光线 → 物品轮廓 Reveal → 物品 PNG → 品质框反馈 → 背景格子染色

弥散仙气 · 三明治遮罩法

极坐标卷环+湍流置换扰乱 → 主体纹理用第三层作亮度蒙版调暗 → 第三层曲线压黑只留亮部脉络，三层叠出若隐若现的仙气。

品质越低光效越短越小；物品出现与主图形纹饰刻意错开一个节奏差，避免双重高光效抢视线。

流光边框

金色扫光沿框体持续流转，可作独立特效节点复用

极坐标 → 色相 → Deep Glow → 发光 → 正方形遮罩 → 混合模式「强光」

02 · 大厅页签按钮终版

常驻入口，需经得起反复凝视：核心难点是复刻高细节国风纹样 + 处理高密度 PSD 的导入工程化。

常驻循环态 · 主纹理渐变 + 星点描边 + 漂浮粒子

嵌套蒙版 PSD 的工程化拆解
STEP 01

带蒙版的组用 Ctrl+J 复制，Ctrl+C/V 会丢失原始位置。

STEP 02

仅显示目标图层，父组转智能对象封装嵌套关系。

STEP 03

右键栅格化，得到位置独立、可直接导入 AE 的图层。

主纹理描边与渐变 · 从半圆到山峦

主纹理独立描边 + 发光层 + 横向渐变过渡

初版只是规则半圆弧，对比参考后改用网格变形雕出古画山峦式的不规则起伏，纹理立刻有了手绘质感；配色建立「中心黄白 → 两侧金黄 → 末端橘金」渐变；多层旋转靠表达式 transform.rotation 同步。

爆点 · 星点描边 · 漂浮粒子
爆点

多层点光相加混合 + 色调调色，堆出入场能量峰值。

星点描边

星点动态拼贴+曲线压密，套图形蒙版，位移与旋转同步蒙版方向。

漂浮粒子

动态拼贴+曲线+湍流置换相加叠加；方向必须「定向」而非「统一」。

混合模式按能量分层：Classic Color Dodge（核心爆点）→ Add（粒子/光束）→ Screen（柔光雾感）；循环态透明度归零，避免常驻过曝显脏。

03 · 飞升倒计时终版

数字跳变 + 中心菱形主体 + 左右流光的入场演出，重心在大体量 PSD 的工程化处理。

04 · 任务完成弹窗终版

核心技术难点是仙气飘带——融合丝绸飘逸感与雾气氤氲感的复合纹理动效。

双层仙气飘带 + CC Light Sweep 高光扫过

仙气飘带 · 双层结构
丝绸层

动态拼贴+偏移关键帧循环，先快后慢缓动，不透明度 50%。

雾气层

同法制作，波速更慢，不透明度 70%，柔化丝绸层。

两层波浪变形后「相加」叠加、三角形蒙版限定范围，叠加原 PSD 贴图统一质感。

流纹走势

贝塞尔+网格变形雕出"先沉后扬"，表达式 [value[0]+time*50,value[1]] 持续偏移。

CC Light Sweep

Edge Intensity Sharp→Smooth，扫光更宽更柔。

05 · 说书人 Tips 终版
与任务完成弹窗共享仙气飘带底层技术，但需长时间停留画面，不能显得机械重复。

多组流纹以差异化相位与速度错落运动

同一素材随机调节波形相位即可让多条流纹形态各异，成本最低的差异化技巧；Tip 入场用前快后慢的位移曲线强化手感。

跨系统方法论
▸动态拼贴+湍流置换+极坐标三件套，通用仙气/流纹生成基础
▸混合模式按能量强度分层管理，而非试错式堆叠
▸骨架固定、唯一替换素材最小化，支撑批量出图
▸高体量 PSD 优先工程化拆解，而非牺牲画质换效率
▸表达式驱动持续动画，减少手动关键帧续接

设计判断：不重复发明技法，而是把验证有效的方法论沉淀为可复用资产，按场景重新分配节奏与形态权重——这是从"做效果"到"搭体系"的分水岭。
