01
整体设计思路
这次设计从海瑟音的角色气质和海洋主题出发，把角色入场、签到页落位、页面呼吸和奖励领取串成一套连续
的动效。入场先建立角色和场景氛围，页面稳定后收回到轻微呼吸，领取奖励时再把动效强度拉高。整体保持
轻盈、通透的水下质感，同时保证签到信息清楚、奖励层级容易识别。
页面里的运动强度按使用状态区分：入场负责吸引视线，呼吸态保持低频，奖励反馈承担短时高潮。这样既保
留角色展示，也不会让常驻动画影响阅读。
签到页最终稳定状态
02
入场设计
开头先用俯拍镜头表现海瑟音踩在水面上的脚步，水纹先把“海”的环境感带出来。随后切到角色拉琴转身的
动作，利用手部向下挥动产生的水光覆盖画面，再承接到海底签到页。镜头切换前后的动作方向保持连续，角
色最后落到页面左侧，签到 Tab 和奖励卡片再依次进入。这样角色演出、场景切换和 UI 出场能够自然连在一
起，也和角色的海洋设定保持一致。

03
页面呼吸态
签到页需要长期停留，所以常驻动画控制在小幅、低频范围。我的处理主要集中在以下几处：
1.
卡片边缘气泡通过湍流置换产生轻微形变，并叠加位置偏移表达式做缓慢漂移；
2.
待领取卡片内部的微光粒子持续上浮，并做轻微亮度呼吸；
3.
卡片表面使用 CC Light Sweep 做低频扫光，强化材质高光；
4.
背景鱼群保持缓慢游动，维持海底空间的流动感；
5.
角色加入轻微呼吸和发丝飘动，让人物停留状态更自然。
这些循环不会使用同一周期。气泡、鱼群、发丝和卡片细节分别错开速度与相位，画面会持续有变化，也不会
出现整页一起“呼吸”的机械感。
a)
气泡呼吸：使用 Turbulent Displace 控制气泡的轻微形变，再叠加 Position 偏移表达式
做持续漂移。形变幅度和位移范围保持较小，避免干扰卡片信息。
b)
粒子收尾：粒子在寿命后段同步缩小和淡出，减少突然消失造成的闪烁感。
c)
卡片扫光：使用 CC Light Sweep 控制扫光的 Center、Direction 和 Width，再压低 
Sweep Intensity 与出现频率，让高光只在卡片表面短暂经过。
常驻状态以低频运动为主，保证信息阅读

04
三种奖励品质的差异
三档奖励沿用同一套中心构图和同心环结构，再通过颜色、光圈数量、粒子密度、冲击和余韵拉开强弱。这样
整体风格统一，品质变化也能直接通过动效强度被感知。
蓝色 · 普通品质
蓝色保留基础环形结构和少量星点，亮度与持续时间都较收敛。重点是把奖励信息清楚地呈现出来，反馈快速
结束。
紫色 · 高级品质
紫色增加主环层级、粒子数量和边框流光，落位时的弹性与亮度更明显，余韵也比蓝色更长。

05
技术实现与工程整理
AE 工程按入场、常驻呼吸、奖励 FX 和 UI 四部分拆分。复杂效果尽量放进独立预合成，主合成只保留关键节奏
和状态切换，方便后续统一调整。
1.
奖励 FX 分层：中心物品、同心环、星点粒子、辉光和背景压暗分别控制。三档品质共用
骨架，只调整层数、强度和持续时间。
2.
冲击点统一：高品质物品落位时，Scale Overshoot、光环扩张、亮度峰值和短促震动放
在同一触发点，再用不同衰减速度退出，反馈会更整齐。
3.
光效合成：黑底光效根据素材使用 Screen / Add，必要时先预合成处理透明度，避免黑底
和颜色发灰。
4.
循环模块独立：鱼群、气泡、卡片微光和角色呼吸各自独立循环，后续可以单独替换或调
整周期。
5.
后续迁移：虽然本次使用 AE 制作，工程结构尽量按 UI、环境循环、奖励 FX、品质参数
拆分，后续在 Unity 中也能按相同逻辑重建。

06
总结
这套动效的重点是把角色入场、页面呼吸和奖励反馈区分清楚：入场负责建立角色和海底氛围，常驻状态保持
轻微流动，奖励领取时再把强度明显拉高。三档品质使用同一套结构逐级增加光效、粒子和冲击，既方便识
别，也方便工程复用。
